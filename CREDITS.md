## Original Creative Claw theme — bundled locally

The owner's original Smart Alec lobby recording is served from `public/sounds/mus-lobby-original.mp3`. `CREATIVE-CLAW-AUDIO-SOURCES.json` records the Creative Claw source URL for provenance; the game does not request it. The previous `mus-lobby.ogg` remains the fallback if the new local file cannot play.
